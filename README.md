# 🍽️ SIMPLY RECIPE

A simple and visually appealing recipe website built using HTML and CSS. Users can browse recipes, explore tags, view individual recipe pages, and more. Ideal as a front-end template or a starting point for integrating dynamic content.

---

## 📁 Project Structure

```
├── 404.html # Custom 404 error page 
├── README.md # This file
├── about.html # About the site or the author
├── contact.html # Contact form or details
├── index.html # Home page listing featured recipes
├── recipes.html # All recipes listing page
├── single-recipe.html # Detailed view of a single recipe
├── tag-template.html # Template page to filter recipes by tag
├── tags.html # Page showing all available tags
```
---

## 💡 Features

- Responsive layout with clean and modern design
- Multiple static pages including:
  - Homepage
  - About and Contact
  - 404 error page
  - Tag-based filtering
